Project Information

Project Title
نظام معالجة عفن البطاطس
(Potato Rot Treatment System)
Project Idea
Creating a smart monitoring system for international potato rot detection and rot reduction.
Problem Definition
Difficulty of instant monitoring for international potato rot, high cost of traditional methods, and absence of immediate alert system.
Problem Objectives
• Providing continuous monitoring for potato quality.
• Providing instant alerts for potato rot.
• Reducing costs and increasing system efficiency.
Expected Contribution
Contributing to increased production, public health protection, environmental protection from rot, and overall efficiency enhancement.
